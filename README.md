# SoundEmpireMonitor

Версия 1.3

SoundEmpireMonitor — tray-приложение для контроля сетевых источников с файлами `Rep_*.db`. Оно отслеживает доступность папок, сообщает о простоях в Mattermost, показывает состояние в трее и не блокирует работу при временно недоступной сети.

## Что умеет

- Проверяет несколько сетевых папок одновременно.
- Делает отложенную перепроверку недоступных источников.
- Показывает окно, если недоступны все источники.
- Отправляет уведомления в Mattermost при старте, пропаже связи, восстановлении и остановке логов.
- Работает в трее и позволяет управлять мониторингом из контекстного меню.

## Быстрый старт

1. Скопируйте `config.example.ini` в `config.ini`.
2. Укажите `webhook_url`, интервал проверки и список папок в формате `Путь|Город`.
3. Запустите `SoundEmpireMonitor.exe`.

## Настройки

В [config.example.ini](config.example.ini) и локальном `config.ini` используются такие параметры:

- `check_interval_seconds` — интервал основной проверки.
- `timeout_minutes` — сколько минут без изменений считать ошибкой.
- `webhook_url` — адрес webhook Mattermost.
- `[Folders]` — список источников в формате `Путь|Город`.

Локальный `config.ini` не рекомендуется публиковать, потому что он содержит webhook и внутренние сетевые адреса.

## Управление

В меню трея доступны:

- `Настройки` — открывает окно редактирования всех параметров.
- `Старт` — запускает мониторинг.
- `Стоп` — останавливает проверку.
- `Exit` — закрывает программу.

## Сборка

Проект собирается как WinForms-приложение на .NET Framework. Для ручной сборки используется `csc.exe` из установленного .NET Framework.

```powershell
& $env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:SoundEmpireMonitor.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll SoundEmpireMonitor.cs
```
