# SoundEmpireMonitor

Версия: 1.3

SoundEmpireMonitor - tray-приложение для контроля нескольких источников логов `Rep_*.db` в сетевых папках. Программа проверяет доступность папок, отправляет уведомления в Mattermost при недоступности источника, при восстановлении, а также при отсутствии изменений дольше заданного порога.

## Возможности

- Мониторинг нескольких сетевых папок одновременно.
- Отложенная перепроверка недоступных источников.
- Экранное уведомление, если недоступны все источники.
- Уведомления в Mattermost при старте, потере связи, восстановлении и остановке логов.
- Работа в трее с меню статуса.

## Настройка

Для локальной настройки скопируйте `config.example.ini` в `config.ini` и заполните значения под свою среду.

Файл `config.ini` содержит:

- `check_interval_seconds` - интервал основной проверки.
- `timeout_minutes` - сколько минут без изменений считать ошибкой.
- `webhook_url` - адрес webhook Mattermost.
- `Folders` - список источников в формате `Путь|Город`.

`config.ini` не стоит коммитить в публичный git, потому что там хранится webhook и сетевые адреса.

## Сборка

Проект собран как обычное WinForms-приложение на .NET Framework. Для ручной сборки используется `csc.exe` из установленного .NET Framework.

Пример:

```powershell
& $env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:SoundEmpireMonitor.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll SoundEmpireMonitor.cs
```
